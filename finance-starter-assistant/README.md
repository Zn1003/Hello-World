# 知账 · 财务上手助手

面向财务系统实施新手的中文学习与工作辅助工具。根据明确业务场景，解释往来科目、借贷方向、分录、余额变化与系统核对要点。

## 使用

无需安装依赖，直接打开 `dist/index.html`。推荐以静态服务器运行，获得稳定的浏览器存储和复制能力：

```sh
python -m http.server 8765 --directory dist --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765 。需要 Node.js 18 或更高版本运行规则测试：

```sh
node --test tests.cjs
```

## 功能

- 14 个场景：应收/应付形成与结算、预款形成与抵扣、员工借还款、保证金收退、撤销核销匹配。
- 科目判断、借贷分录、部分核销余额和预款余额校验。
- 区分本次记账、凭证已记账后仅匹配、只撤销匹配。
- 六类常见往来科目速查、8 道解释式练习题。
- 案例在浏览器 localStorage 保存，可载入、删除、导出 JSON 备份。
- 蓝白主题，手机底部导航、16px 以上表单输入字号、触控大按钮与安全区适配。
- 手机提交后自动定位到结果，可一键返回修改；分录与余额按窄屏排版。
- 练习进度条与即时得分反馈，支持减少动态效果的系统偏好。
- 响应式布局，无后端、无构建步骤、无外部 JavaScript 依赖。

## 会计口径

始终站在本公司角度。适用于常见企业人民币往来业务的基础教学，不含税额拆分、折扣、汇兑差额、坏账和债务重组。赊购示例假设货物已入库，赊销示例假设已满足收入确认条件，未展示销售成本结转。实际以企业会计政策、科目设置、业务流程为准。

核销是匹配与结算的业务动作，是否生成凭证取决于记账环节。反核销匹配不会自动冲销原凭证。页面中的未核销余额与总账余额必须分开核对。

来源和适用口径见页面「科目速查」。本工具使用确定性规则，没有接入大模型，也不会上传用户案例。浏览器清理、切换设备或更换站点会影响本地案例，建议导出备份。

## 文件

- `dist/engine.js`：以整数分计算金额的独立业务规则模块。
- `dist/app.js`：页面交互、练习和本地案例。
- `dist/styles.css`：桌面与手机样式。
- `tests.cjs`：金额、分录、核销及反核销规则测试。

将 `dist/` 作为静态网站根目录即可部署。线上 Sites 部署使用独立源仓库，此 GitHub 仓库保存可独立运行的应用代码，不包含凭证或真实业务数据。
