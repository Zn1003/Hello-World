知账手机版 · 安卓纯前端离线版

你只需要“知账手机版.html”这一个文件，不用安装 Python、Node.js，不用启动电脑服务，不用登录 GitHub 或 ChatGPT。

【传到安卓手机】
1. 将“知账手机版.html”通过数据线、微信文件传输助手、QQ 或其他文件传输方式发送到手机。
2. 先把文件下载到手机“下载/Download”或“文档”文件夹。若传的是 ZIP，请先解压。
3. 在手机文件管理器中找到“知账手机版.html”，选择“打开方式”，用支持运行本地 HTML/JavaScript 的浏览器打开。
4. 如果聊天软件内只是显示源代码、静态预览或按钮点不动，请退出预览，从文件管理器重新选择浏览器；不同安卓系统和浏览器的本地文件支持存在差异。本版本未在实体安卓手机上验证。
5. 打开成功后可以断开网络，业务判断、速查和练习不需要联网。页面中的“来源链接”需要联网才能访问。

【功能】
蓝白手机界面；14 个业务场景；六类往来科目速查；8 道场景练习；案例保存、导出与导入。
没有后台服务、网络请求、外部字体、外部脚本或登录流程。所有计算在手机本地完成。

【数据保存】
案例和练习进度会尝试写入当前浏览器的本地存储。部分浏览器在本地文件模式下不支持持久保存，页面会给出提示。
若更换浏览器、清理浏览器数据、重命名或移动 HTML 文件，历史案例和练习进度可能无法继续读取。重要案例请及时在“案例”页导出 JSON 备份。
导出文件在“案例 → 导入备份”中选择后会与当前案例合并，相同业务与金额的案例不重复导入；导入前会验证整个文件，格式错误时不修改现有案例。
旧版知账导出的 version=1 案例 JSON 也可导入。练习进度保存在当前浏览器，不包含在案例备份中。
浏览器不支持自动复制时，点击“复制解释”会显示文本，长按即可手动选择复制。

【适用口径】
基础教学示例使用人民币，不拆分税额，不处理折扣、汇兑、坏账和债务重组。具体以企业会计政策与实际账套为准。
“仅匹配核销”与“记账”不同，“撤销匹配”不自动冲销凭证。不要将未核销单据金额直接等同于总账余额。

【开发】
src/ 是独立源码。修改后在本目录执行 python build.py 重新生成发布文件。
业务规则测试：node --test engine.test.cjs portable.test.cjs
打包校验：python verify.py
